## Project Overview / Описание на проекта

Проекта представлява концепция за начална страница за VS DANCE Studios, с фокус над изчистена и ясна навигация, добре структурирано и достъпно съдържание, праволинеен път към откриването и избора на подходяща опция за обучение.

Това репозитори съдържа front-end имплементация и кратък анализ, подготвени като част от поставеното задание.

## Technologies / Технологии

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design

## External Dependencies / Външни зависимости

Проекта не използва външни js фреймуъркове и зависимости.

Шрифтовете са включени в проекта и се зареждат, чрез CSS @font-face.

## Getting Started / Как да започнем

Проекта е статична html/css/javascript страница и като такъв, не изисква билдване или инсталиране/сваляне на пакети.

За да стартирате проекта при вас локално е необходимо да:

1. Клонирате репозиторито.
2. Отворите index.html файла в избран от вас уеб браузър.


## Accessibility / Достъпност

Имплементацията включва:

- семантична HTML структура
- достъпни етикети за навигация
- aria-expanded и aria-controls за мобилното меню
- поддръжка на клавиша Escape за затваряне на мобилното меню
- възстановяване на фокуса след затваряне на менюто с Escape
- поддръжка на prefers-reduced-motion
- подходящ алтернативен текст за информативните изображения

## SEO / СЕО

Реализацията включва основна SEO:

- описателно заглавие на страницата
- мета описание
- декларация на езика на документа
- семантична структура на заглавията
- съдържание в HTML, подлежащо на индексиране от търсещи машини
